# Teer Blog Content Generator Instructions

- **Objective**: Write human-like, natural, and highly engaging SEO content.
- **Audience**: Teer market audience in Meghalaya, Assam (Shillong, Khanapara, Juwai).
- **Keywords**: Integrate long-tail keywords (e.g., "Shillong teer result prediction today", "Live teer result today", "Teer common numbers today").
- **Language**: English, but maintain a local, trustworthy, and simple tone.
- **Structure**:
  - Main Title (H1)
  - Secondary Sections (H2, H3)
  - Clear, readable paragraphs.
  - An FAQ section at the bottom containing 2-3 common questions.
- **Internal Linking**: Suggest internal anchor texts (e.g. `[Check Live Results](/live)`) naturally within the text.
- **Format**: Return the output strictly as a JSON object containing the exact following keys:
  - `title`: A catchy, click-through-rate optimized title.
  - `slug`: The desired URL slug (e.g., `shillong-teer-prediction-today`).
  - `meta_description`: A 150-160 character meta description.
  - `content`: The raw Markdown payload matching the structural requirements above.
